# C 题：自主循迹与定点停车运动控制系统 —— 固件实现说明

把《C题-自主循迹与定点停车运动控制系统》的每一条指标落到具体代码、参数和判定条件上，
同时对应设计报告的“方案论证 / 理论分析 / 电路与程序设计 / 测试方案”四栏。

- 芯片：MSPM0G3507（WHEELTEC 地猛星小车板）
- 工具：CCS 21.0.1 + MSPM0 SDK 2.11 + SysConfig 1.26，工程名 `wheeltec_car_g3507`
- 规模：**12.6 KB Flash / 1.1 KB RAM**，11 个 `.c`，编译零告警
- 命令行编译：`powershell -ExecutionPolicy Bypass -File .\build.ps1`

## 1. 控制链路

```
        ┌──────────── 八路红外灰度（PA17/PB8/PB9/PA24/PA2/PA0/PA1/PA23）
        │                    │ line_sensor.c
        │                    │ 加权平均求黑线横向偏差 pos(mm)
        │                    ▼
        │             line_follow.c  PD
        │             base = 巡航速度 - 3.5×|pos|      （弯道自动减速）
        │             corr = Kp·pos + Kd·d(pos)/dt
        │             L = base + corr, R = base - corr
        │                    │
按键 PA16 ─► button.c ─► mission.c（6 项状态机）─► control.c（轮速环）─► motor.c（TB6612）
        │                    ▲
        │             odom.c │ 里程 d、转角 ψ
        └── 编码器 PA21/PA22、PB19/PB20 ──┘
```

固件里只有这一条链：没有遥控协议、没有 Flash 存参、没有电池检测，上电就是比赛状态。

## 2. 七项要求逐条对照

| 题目要求 | 代码位置 | 判定条件 | 主要参数 |

| 1. 顺时针 1 圈停 A，≤40 s，偏差 ≤5 cm | `mission.c: run_laps()` | 里程 ≥6140 mm 或识别到 A 点启停线 | `CAR_SPEED_ITEM1_MM_S=260` |
| 2. 逆时针 1 圈停 A，≤20 s，偏差 ≤5 cm | 同上（巡线本身不分方向） | 同上 | `CAR_SPEED_ITEM2_MM_S=420` |

| 4. A→B 停 3 s，倒车回 A，≤30 s | `run_shuttle()` | 前进 ≥1500 mm 停 → 停 3 s → 倒回 0 mm 停 | `CAR_SPEED_ITEM4_MM_S=300` |
| 5. 原地顺时针 90°，停 3 s，再逆时针 90° 转回，≤20 s | `run_turn()` | 编码器差速积分角 | `CAR_TURN_ITEM5_DEG=-90` |
| 6. 线外 20~40 cm 白区自主找线，顺时针到 A 停，≤30 s | `run_seek()` | 原地扫 370° → 没找到就前进 80 mm 再扫 | `CAR_SEEK_*` |
| 7. 设计报告 | 本文件 + README + 代码注释 | —— | —— |

### 2.1 一圈的距离基准

AB、CD 各 1.5 m 直道，BC、DA 是 R=0.5 m 半圆，中心线周长

```
L = 1.5 + 1.5 + π×0.5 + π×0.5 = 6.14 m
```

代码里 `CAR_LAP_LENGTH_MM = 6140`。**里程是从轮子转出来的**，所以停车精度最终取决于
“编码器 → 毫米”的标定，而不是启停线识别的快慢。

### 2.2 启停线怎么认，为什么不靠它停车

启停线长 5 cm、宽 1.8 cm，垂直压在 1.8 cm 黑线上。8 路灰度间距 11 mm、总跨度 77 mm：

- 正常巡线（1.8 cm 线宽）：同时压线 1~2 路，斜着过弯最多 3 路；
- 压到启停线：同时压线 4~5 路。

所以 `CAR_LINE_MARKER_MIN = 4` 就能把两者分开，再连续 2 个节拍确认。

**但停车判定不依赖它**：车头最前端是判定点，灰度条在车头后面 3~4 cm；车头正好停在启停线上时，
灰度条还差 3~4 cm 才压到线，等它压到线车头已经过线，正好把 5 cm 预算吃掉一大半。所以：

1. **主判据是里程**：目标 = `圈数 × 6140 + CAR_STOP_TRIM_MM`；
2. 启停线只用来**核对圈数**：A 点在里程 0 / 6140 / 12280 … 处，B 点在 1.5 m（顺时针）
   或 4.64 m（逆时针）处，用“到周长整数倍的距离 < 400 mm”把 A 和 B 分开；
3. 因此 B 点启停线不会被误当成 A 点。

### 2.3 停车精度怎么保证（≤5 cm）

| 措施 | 作用 | 参数 |
|---|---|---|
| 停车前 26 cm 切爬行（110 mm/s） | 从 0.56 m/s 直接刹会冲 5 cm 以上；爬行时刹车距离只有 2~3 mm | `CAR_STOP_SLOW_ZONE_MM`、`CAR_SPEED_CREEP_MM_S` |
| 编码器 0.13 mm/计数 | 1560 计数/转、周长 204.2 mm，里程量化误差可忽略 | `CAR_ENCODER_PPR`、`CAR_GEAR_RATIO`、`CAR_WHEEL_DIAMETER_MM` |
| `CAR_STOP_TRIM_MM` 一维标定 | 吸收轮径磨损、地面滑移、车头判定点安装误差 | 默认 0，按实测 `dev` 改 |

### 2.4 第 4 项：倒车为什么用航向保持

灰度装在车头，倒车时车头在后，用灰度纠偏等于拿滞后传感器做非最小相位控制；
AB 段又是 1.5 m 直线，用编码器航向保持更稳：

```
ψ_ref = B 点停稳 3 s 结束时的 ψ
u = 0.55 × (ψ - ψ_ref)          // 百分比
L = -base + u,  R = -base - u
```

### 2.5 第 5 项：没有陀螺仪怎么转 90°

```
ψ = Σ (Δs_R - Δs_L) / 轮距 × 180/π
```

轮距 `CAR_WHEEL_BASE_MM = 130`（**必须实测两轮接地点间距**）。转 90° 对应差速里程
= π/2 × 130 ≈ 204 mm ≈ 1560 个计数，分辨率足够。

角度环是“比例 + 角速度阻尼”：

```
u = Kp·(目标 - ψ) - Kd·ψ̇        Kp=1.0, Kd=0.10
```

只给比例时，为克服静摩擦必须留 12% 的最小占空比，车会在目标角两侧来回摆，
“连续 15 拍都在 ±2.5° 内”永远满足不了；加阻尼后到位前先反向制动，才能真正停住。

转向方向：顺时针（负角度）默认对应“车头指向环路内侧”。装车后发现该往另一侧，
把 `CAR_TURN_ITEM5_DEG` 改成 `+90.0f`。

### 2.6 第 6 项：找线与一个绕不开的歧义

1. `PH_SEEK_ROT`：原地顺时针慢扫（16%），最多 370°；
2. 扫一圈没看到黑线 → `PH_SEEK_FWD` 直行 80 mm 再扫，最多 6 轮（覆盖约 40 cm）；
3. 任意一路压到黑线 → `PH_APPROACH`：以 110 mm/s 慢速前进，用 PD 把黑线拉到中间，
   连续 10 拍居中才切正常巡线；
4. `PH_TRACK`：按 320 mm/s 巡线，遇到第 1 条启停线停车。

**歧义说明（写进报告更显严谨）**：题目只在 A、B 两处画了启停线，两者尺寸颜色完全一样，
也没有其它绝对位置基准，单靠红外灰度**无法区分 A 和 B**。本实现按“裁判把车放在 A 附近”
这一前提取第 1 条启停线（`CAR_ITEM6_STOP_MARKERS=1`）。若实测发现会先经过 B 点，改成 2。

### 2.7 时间预算（按纸面速度估算，需上车实测）

| 项 | 巡航速度 | 理论行驶 | 减速/停留 | 估计总时 | 限时 |
|---|---|---|---|---|---|
| 1 | 260 mm/s | 6.14/0.26 = 23.6 s | +2.4 +1 | **≈27 s** | 40 s |
| 2 | 420 mm/s | 14.6 s | +2.4 +1 | **≈18 s** | 20 s |
| 3 | 560 mm/s | 18.42/0.56 = 32.9 s | +2.4 +1 | **≈36 s** | 40 s |
| 4 | 300 mm/s | 3.0/0.30 = 10 s | +4.8 +3 | **≈19 s** | 30 s |
| 5 | 转 90° | 2×1.5 s | +3 +0.3 | **≈7 s** | 20 s |
| 6 | 320 mm/s | 找线 5 s + 19.2 s | +2.4 | **≈27 s** | 30 s |

> 第 3 项最紧：18.42 m / 40 s = 0.46 m/s 平均，几乎要跑到 90% 占空比。
> 如果实车 100% 达不到 560 mm/s，把 `CAR_MAX_SPEED_MM_S` 改成实测的 100% 轮速，
> 速度指令才会和 mm/s 对得上（否则 PID 会长期饱和）。

## 3. 操作与串口

| 操作 | 效果 |
|---|---|
| 短按 PA16 | 开始当前项目；运行中按下 = 中止停车 |
| 长按 PA16 | 切换项目 1→2→…→6 |
| 串口 `1`~`6` / `P` / `X` / `S` | 选项目 / 开始 / 中止 / 打印状态 |

运行中 2 Hz 输出状态帧：

```
$D,item=1,st=2,ph=1,t=12340,d=3210,pos=-8,blk=2,corr=12,lap=0,mk=0
```

结束输出结果帧：

```
$R,item=1,ok=1,why=0,t=26750,d=6110,dev=-30,yaw10=0,lap=1,mk=2
```

- `st`：0 待机 / 1 待启动 / 2 运行 / 3 完成 / 4 失败
- `why`：1 超时 / 2 堵转 / 3 丢线 / 4 找不到线 / 6 人为中止
- `dev`：实际停车点相对目标的偏差（mm）——**标定就看这个数**
- `yaw10`：结束时车头角度 ×10（第 5 项看这个）

## 4. 上车标定顺序（一步别跳）

### 步骤 0：架空轮子查方向

1. 车上电，短按开始跑第 1 项（轮子悬空）；
2. 两个轮子都应向“车头方向”转，反了改 `CAR_LEFT_INVERT` / `CAR_RIGHT_INVERT`；
3. 串口按 `S`，确认 `blk` / `pos` 会随黑线位置变化。

### 步骤 1：灰度极性与顺序（错了车会直接冲出去）

1. 手拿小车把灰度条压在黑线上，按 `S` 看 `blk`：
   - 压黑线 `blk` 应 ≥1；若压黑线反而是 0、压白纸是 8，把 `CAR_LINE_BLACK_LEVEL` 改成 `1`；
2. 把黑线放在车体**右侧**，`pos` 应为**正数**；若为负，改 `CAR_LINE_SENSOR_REVERSE = 1`。

### 步骤 2：里程标定（决定 1 圈和 90°）

1. 在直道上量 1.00 m，把车摆好，上电后手推走完 1 m（**不要按开始**）；
2. 按 `S` 读 `d`，应在 1000±20 mm；偏大偏小按比例改 `CAR_WHEEL_DIAMETER_MM`；
3. 用卷尺量两轮接地点间距，填进 `CAR_WHEEL_BASE_MM`。

### 步骤 3：循迹 PD

低速跑第 1 项：

- 左右画龙 → 减小 `CAR_LINE_KP`；
- 进弯反应慢、冲出去 → 加大 `CAR_LINE_KP`；
- 高速抖动 → 加大 `CAR_LINE_KD`。

### 步骤 4：停车标定

1. 摆好 A 点跑第 1 项，看 `$R` 的 `dev=`（例如 `dev=-30` 表示少了 30 mm）；
2. 把 `CAR_STOP_TRIM_MM` 设成 `-dev`（上例填 30）；
3. 连跑 3 次，`dev` 稳定在 ±10 mm 内即可。

### 步骤 5：其余项目

- 第 4 项：先看 B 点停得准不准（同样看 `dev`），再看倒车回 A 偏不偏；
  倒车画龙减小 `CAR_BACK_YAW_KP`，回不正加大。
- 第 5 项：跑第 5 项看 `yaw10`，到位应在 ±25（±2.5°）内；
  冲过头加大 `CAR_TURN_KD`，转不动加大 `CAR_TURN_MIN_PCT`。
- 第 6 项：把车放线外 30 cm、车头随便指，短按开始，看能否找到线并跑到 A。

### 步骤 6：完整流程

六项按顺序各跑 2 次（规则允许每项 2 次取最好），记录时间、`dev`、`yaw10`，
这组数据就是报告“测试方案与测试结果”的原始表格。

## 5. 安全设计（答辩会被问）

| 机制 | 说明 |
|---|---|
| 项目超时 | 每项“限时 + 8 s”硬超时，超时立即停车，`why=1` |
| 堵转保护 | 目标在动但轮速持续 1.2 s 接近 0 → 停车，`why=2` |
| 丢线保护 | 巡线连续丢线 1 s → 停车，`why=3`（第 6 项找线阶段不受此限） |
| 软启动 | 占空比每 10 ms 最多变 4%，不会一给指令就猛冲 |
| 按键中止 | 运行中短按按键 = 立即停车 |

## 6. 已知限制

1. **没有陀螺仪**：90° 靠轮速积分，打滑会累积误差；轮距填错会按比例偏
   （填 130 实为 140，90° 会转成 83.6°）。以后加 MPU6050 只需替换 `odom_yaw_deg()` 的数据源。
2. **没有 OLED**：用串口 `$D` 帧当显示。加 0.96" SSD1306 只需在 `car.syscfg` 加 I2C1（PB2/PB3），
   定时读 `mission_elapsed_ms()` / `mission_distance_mm()` 即可。
3. **A/B 启停线不可区分**（见 2.6），第 6 项按“车放在 A 附近”实现。
4. **速度换算基准要实测**：`CAR_MAX_SPEED_MM_S` 是“100% 占空比对应多少 mm/s”的假设值，
   必须按实车标定，否则所有 mm/s 指令都会系统性偏快或偏慢。
